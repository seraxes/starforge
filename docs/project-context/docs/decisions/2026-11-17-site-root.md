# Decision: site root

**Date:** 2026-11-17

**Decision:** Navigation owns one root item for the whole site (`sf_site_settings.root_item`: menu id + item id). `/{locale}` opens that same page, module view, or internal path in the requested language. A missing field uses Localization’s `defaultLocale` only while `localeFallback` is on. The target’s own path redirects to `/{locale}`. Slug `home` is the root only while no item is marked Root. A locale does not get its own root item, and slugs stay shared.

**Constraint (one sentence an agent can follow):** Do not hard-code slug `home` as `/{locale}` once `rootItem` is set; Navigation writes that one pointer, Localization owns `defaultLocale` and `localeFallback`, and do not add a menu per language.
